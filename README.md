# 🎨 Estudo de Display — CSS

Projeto criado para estudar a propriedade `display` do CSS e entender, na prática, como cada valor altera o comportamento e o posicionamento dos elementos HTML.

## 📚 Sobre o projeto

A propriedade `display` é uma das principais ferramentas do CSS para controlar como um elemento é exibido na página.

Neste projeto, cada exemplo demonstra um tipo de `display`, permitindo visualizar suas diferenças e entender quando utilizar cada um.

## 🧩 Displays estudados

- `display: block`
- `display: inline`
- `display: inline-block`
- `display: flex`
- `display: grid`
- `display: none`

### `block`

O elemento ocupa toda a largura disponível e começa em uma nova linha.

```css
.elemento {
  display: block;
}
````

### `inline`

O elemento ocupa apenas o espaço necessário para seu conteúdo e permanece na mesma linha que outros elementos.

```css
.elemento {
  display: inline;
}
```

### `inline-block`

Combina características de `inline` e `block`: o elemento permanece na mesma linha, mas permite definir propriedades como `width` e `height`.

```css
.elemento {
  display: inline-block;
}
```

### `flex`

Utilizado principalmente para organizar elementos em uma dimensão, seja em linha ou em coluna.

```css
.container {
  display: flex;
}
```

É muito útil para criar layouts, alinhar elementos e distribuir espaços.

### `grid`

Permite criar layouts baseados em linhas e colunas.

```css
.container {
  display: grid;
}
```

É especialmente útil para estruturas de layout mais complexas.

### `none`

Remove o elemento da renderização da página.

```css
.elemento {
  display: none;
}
```

O elemento deixa de ocupar espaço no layout.

## 🎯 Objetivo

O objetivo deste projeto é praticar CSS e compreender visualmente as diferenças entre os principais valores da propriedade `display`.

A ideia é experimentar os exemplos, modificar o CSS e observar como o layout se comporta.
